## How to Contribute

There are many ways you can contribute:

- Reporting bugs and issues
- Suggesting features and enhancements
- Submitting pull requests for improvements and bugfixes
- Improving documentation

## Getting Started

### 1. Fork the Repository

Click the **Fork** button at the top right of this page, then clone your forked repo:

```bash
git clone https://github.com/YOUR_USERNAME/energy-monitor-app.git
cd energy-monitor-app
```

### 2. Install Dependencies

**Frontend (React, TypeScript):**
```bash
cd frontend
npm install
```

**Backend (Spring Boot, Java):**
Import the `backend` directory into your favorite Java IDE (e.g., IntelliJ, Eclipse) and build with Maven or Gradle.

### 3. Set Up Environment

- Copy and update environment variables as needed (see `.env.example` files).
- Set up the MySQL database and update backend configuration.

## Development Guidelines

- Write clear, concise commit messages.
- Ensure your code follows existing patterns and conventions.
- Write tests for new features or bug fixes.
- Keep pull requests focused and atomic.

## Pull Request Process

1. Create a new branch from `main` (e.g., `feature/your-feature`).
2. Make your changes and commit them.
3. Push to your fork and open a pull request.
4. Fill out the pull request template and describe your changes.
5. Ensure all tests pass and your code is linted.
6. Participate in the code review process.

## Reporting Issues

If you find a bug or have a question, please [open an issue](https://github.com/LukasZaw/energy-monitor-app/issues/new/choose) and provide as much detail as possible.

## Feature Requests

We welcome suggestions! Please use the **Feature Request** issue template and describe your idea clearly.

## Style Guide

- **Frontend:** Follow the code style from existing React, TypeScript, and Tailwind CSS code.
- **Backend:** Adhere to Java and Spring Boot best practices.
- Use descriptive variable and function names.

## Contact

For major contributions or questions, reach out via GitHub or file an issue.
